# Agile Planner

Персональный Agile-планировщик — консольная программа для ведения личного
бэклога задач, планирования спринтов и отслеживания хода работ на
канбан-доске.

Проект выполняется в рамках рейтинговой работы по дисциплине
«Проектная деятельность в ИТ» (вариант «Разработка программы планировщика
Agile для личного пользования»).

## Возможности

- ведение бэклога: добавление, просмотр и удаление задач;
- приоритет и оценка трудоёмкости задачи в условных единицах (story points);
- планирование спринта и включение в него задач из бэклога;
- канбан-доска со статусами «Бэклог», «К выполнению», «В работе», «Готово»;
- расчёт выполненного объёма работ за спринт (velocity);
- хранение данных в локальном файле формата JSON.

## Структура репозитория

| Каталог / файл | Назначение |
| --- | --- |
| `docs/` | проектная документация (требования, ИСР, архитектура, руководство) |
| `src/` | исходный код программы |
| `tests/` | модульные тесты |
| `CHANGELOG.md` | история версий |

## Ветки и жизненный цикл проекта

| Ветка | Этап жизненного цикла |
| --- | --- |
| `main` | стабильная версия проекта |
| `analysis` | 1. Анализ и планирование |
| `design` | 2. Проектирование |
| `development` | 3. Разработка |
| `testing` | 4. Тестирование |
| `deployment` | 5. Внедрение и сопровождение |

## Запуск

Требуется Python версии 3.9 или выше, сторонние библиотеки не нужны.

    python src/planner.py --help
