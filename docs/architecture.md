# Проектные решения

## 1. Архитектура

Программа состоит из трёх слоёв, размещённых в одном модуле `src/planner.py`:

| Слой | Элемент | Назначение |
| --- | --- | --- |
| Интерфейс | функции `build_parser`, `main` | разбор команд пользователя и вывод результата |
| Логика | класс `Planner` | операции над задачами и спринтами |
| Хранение | методы `load`, `save` | чтение и запись файла `planner_data.json` |

## 2. Модель данных

Задача (`task`):

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | целое | уникальный номер задачи |
| `title` | строка | название задачи |
| `priority` | целое 1–5 | приоритет (1 — наивысший) |
| `points` | целое | оценка трудоёмкости в story points |
| `status` | строка | `backlog`, `todo`, `in_progress`, `done` |
| `sprint` | строка или пусто | название спринта, в который включена задача |
| `created` | дата | дата создания |

Спринт (`sprint`): название, дата начала, длительность в днях.

## 3. Интерфейс командной строки

| Команда | Действие |
| --- | --- |
| `add "название" -p 2 -e 3` | добавить задачу в бэклог |
| `board` | показать канбан-доску |
| `sprint "название" -d 7` | начать новый спринт |
| `plan ID` | включить задачу в текущий спринт |
| `move ID статус` | изменить статус задачи |
| `stats` | показать выполненный объём работ за спринт |
| `delete ID` | удалить задачу |
