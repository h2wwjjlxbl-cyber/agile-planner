# Требования к программе «Agile Planner»

## 1. Назначение

Программа предназначена для планирования и учёта личных задач одного
пользователя с применением гибких (Agile) практик: бэклог, спринт,
канбан-доска.

## 2. Пользователи

Единственная категория пользователей — владелец планировщика, работающий
с программой на личном компьютере.

## 3. Функциональные требования

| Код | Требование | Приоритет |
| --- | --- | --- |
| FR-01 | Добавление задачи в бэклог с названием, приоритетом и оценкой | высокий |
| FR-02 | Просмотр задач в виде канбан-доски по статусам | высокий |
| FR-03 | Изменение статуса задачи | высокий |
| FR-04 | Создание спринта с названием и длительностью | средний |
| FR-05 | Включение задачи из бэклога в текущий спринт | средний |
| FR-06 | Расчёт выполненного объёма работ за спринт | средний |
| FR-07 | Удаление задачи | низкий |

## 4. Нефункциональные требования

| Код | Требование |
| --- | --- |
| NFR-01 | Программа работает в ОС Windows, Linux и macOS |
| NFR-02 | Данные хранятся локально в файле формата JSON |
| NFR-03 | Для работы не требуется подключение к сети Интернет |
| NFR-04 | Для запуска достаточно стандартной поставки Python 3.9+ |

## 5. Критерии приёмки

1. Все функциональные требования с высоким и средним приоритетом реализованы.
2. Модульные тесты выполняются без ошибок.
3. Подготовлено руководство пользователя.
